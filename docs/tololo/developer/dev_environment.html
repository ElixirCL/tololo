🔭 Setting Up a Development Environment

We recommend using Devenv to manage system dependencies and services. After cloning the repository, the devenv.nix file at the root of the project creates a reproducible development environment.

Options to Run Devenv

  1. Installing Nix Follow the steps on this page. and Devenv.

  2. Using a Dev Container: Follow the steps on this page. This repository includes a devcontainer.json file with Devenv.

Tested with 'devenv-1.3.1'

After Setting Up Devenv

  • Enter a shell:

$ devenv shell

  • Start services (for example, Postgres):

$ devenv up

  • Set up the project (after entering shell):

$ mix setup

These commands are available in the project Makefile

Troubleshoot

Error: You’re not a trusted user of the Nix store.

This means that the file /etc/nix/nix.conf lacks the trusted users configuration.

  • 1. Open the file with write privileges.

$ sudo vim /etc/nix/nix.conf

  • 2. Add the trusted users.

trusted-users = root camilowser

  • 3. Reboot nix service

sudo launchctl kickstart -k system/org.nixos.nix-daemon

Environment Variables

When using commands like devenv shell the --impure flag must be used.

  • NIXPKGS_ALLOW_UNSUPPORTED_SYSTEM=1: Will allow install unsupported packages. For example inotify-tools is not supported in MacOS (darwin). Compilation is not garanteed though.
