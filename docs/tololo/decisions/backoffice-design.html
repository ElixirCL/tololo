Design for backoffice

  • Status: accepted

  • Date: 2025-01-06

Context and Problem Statement

We want to leverage existing UI libraries to quickly iterate over the admin panel of the solution while focusing on functionality over design.

Considered Options

  • Backpex: Highly customizable administration panel for Phoenix LiveView applications. Doesn’t support Ash currently.

  • live_admin: Low-config admin UI for Phoenix apps, built on LiveView and Ecto.

  • AshAdmin: A super-admin UI dashboard for Ash Framework applications, built with Phoenix LiveView. It’s not suitable for being distributed to end-users.

  • Tailwind admin dashboard template such as TailAdmin: Templates built with Tailwind, mostly just designs.

Decision Outcome

Chosen option: “Tailwind admin dashboard template”, because

  • Allows for deep customization.

  • Has no integration issues with the planned stack.

Positive Consequences

Using already built Tailwind components will allow contributors focus on the functionalities rather than the design.

Negative Consequences

Integration with the rest of the solution will need to be implemented from scratch.
