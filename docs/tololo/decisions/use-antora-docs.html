Use Antora Docs

  • Status: accepted

  • Date: 2025-01-08

Context and Problem Statement

We need to create all the documents for project decisions, tutorials, articles and developer documentation. A single place and tool to keep all the relevant information.

Considered Options

  • Mdbook: Official tool for documentation creation within the Rust community. A simple but powerful tool that works with Markdown.

  • Docusaurus: A documentation tool that uses React.js and Markdown.

  • Antora Docs: A documentation tool using Asciidoc as the main markup language.

Decision Outcome

Chosen option: “Antora Docs”, because:

  • Asciidoc have a standarized markup, where Markdown have different "flavours".

  • Antora Docs creates great looking and customizable websites.

  • Asciidoc is easily integrated with many diagramming tools (PlantUML, DBML) using Kroki.

Consequences

  • Antora Docs will be used as the main documentation tool for business logic and user related documents.

  • Low level developer API documentation will be created with Elixir Hex Docs. And referenced by a link to Hexdocs in Antora Docs generated documentation.
