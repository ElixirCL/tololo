= Extensions

Eatsbot is based with extensibility in mind. This means it supports optional extensions
that can be enabled or disabled. For example a Telegram Bot extension that will
make available a Telegram chatbot, or optional Prometheus and Grafana metrics.

An extension is a traditional _Elixir_ project with its own `mix.exs` file and dependencies
that is imported in the main `mix.exs` file.

== Adding an extension

To add an extension simply add it to the main `mix.exs` in the deps.

[source, elixir]
----
{:eatsbot_extension_telegram_bot,
       path:
         Path.join(["extensions", "telegram_bot"])
         |> Path.expand()},
----

== Architecture

The project is structured using the following components

- Core: Code that is required for extensions and is shared across them. The application cannot function with out code inside core.
- Extensions: Code that can be optional to be used in Main.
- Main: This is the Phoenix Application that must import Core and optional Extensions.

== Extensions Capabilities

An extension can have the following capabilities:

- Can add new routes.
- Can add new controllers.
- Can add new views and liveviews.
- Can have own gettext translations.
