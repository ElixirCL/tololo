=== Configuration

Expects the following environment variables:
- `TELEGRAM_WEBHOOK`: a full URL, such as https://your.domain.com/telegram. The URL must be suffixed with /telegram, because this is where the webhook route is configured.
- `TELEGRAM_TOKEN`: an access token for the bot you with to use. You can obtain one https://core.telegram.org/bots/tutorial#obtain-your-bot-token[following these instructions].
