= 🔭 Setting Up a Development Environment

We recommend using __Devenv__ to manage system dependencies and services. After cloning the repository, the __devenv.nix__ file at the root of the project creates a reproducible development environment.

== Options to Run Devenv

1. Installing Nix
   https://devenv.sh/getting-started/[Follow the steps on this page.]

2. Using a Devcontainer
   https://code.visualstudio.com/docs/devcontainers/containers#_quick-start-open-an-existing-folder-in-a-container[Follow the steps on this page.] This repository includes a devcontainer.json file with Devenv.

== After Setting Up Devenv

- Enter a shell:  
  ....
  devenv shell
  ....

- Start services (for example, Postgres):  
  ....
  devenv up
  ....

- Set up the project (after entering shell):
  ....
  mix setup
  ....
